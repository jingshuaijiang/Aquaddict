# 潜水日志 iOS App 设计文档

日期：2026-08-10
状态：待用户确认

## 目标

一个自制 iOS 潜水日志 app，直接通过 BLE 从 Shearwater 潜水电脑（用户持有 Perdix 3 和 Peregrine，需支持全系 BLE 型号）下载潜水日志，本地存储、可视化、训练分析。界面要"酷"——现有潜水 app 的表格式审美是明确要超越的对象。

**不做**：蓝牙 Classic 老型号（Predator / Petrel 1/2，iOS 平台无法连接）、云同步、社交功能、照片（列为未来扩展）。

## 技术路线（已确认：方案 A，纯 Swift）

- **UI**：SwiftUI，iOS 17+
- **蓝牙**：CoreBluetooth，自行实现 Shearwater BLE 协议（参照 libdivecomputer 的 `shearwater_common.c` / builder555 的协议文档）
- **日志解析**：Swift 移植已验证的 PNF 解析器（本仓库 `parse_dives.py`，字段偏移已用 47 潜真实数据核对）
- **存储**：SwiftData（每潜 = 元数据 + 原始 PNF blob + 解析后采样；保留原始 blob 使未来格式修正可重解析）
- **图表**：Swift Charts；**地图**：MapKit
- **双语**：String Catalog（.xcstrings），中英文跟随系统设置自动切换

### 为什么"支持所有型号"是可行的

Shearwater 全系 BLE 型号共用同一套传输协议（serial-over-GATT）和 PNF 日志格式。为两台设备写的代码即天然覆盖 Petrel 3、Teric、Tern、NERD 2、Perdix AI/2 等。风险兜底：若协议实现遇到死角，可引入 libdc-swift（LGPL，个人使用无碍）作 Plan B。

## 界面结构（2 个 Tab）

### Tab 1：日志（主界面）

自上而下：

1. **上一潜卡片**（英雄区）：多曲线图——深度为主线，叠加水温、NDL/TTS；有 AI 发信器时自动叠加气瓶压力/RMV。每条线带图例标注。
2. **下载按钮** → 设备选择弹层（配对与下载 UX）：
   - **首次配对**：用户把潜水电脑调到 Bluetooth 模式（Menu → Bluetooth），app 按 Shearwater 的 BLE service UUID 过滤扫描，「附近的新设备」列出 `型号 [序列号]`，点击即配对并存入「我的设备」。无需 iOS 系统级配对，纯 app 内 GATT 连接。
   - **日常下载**：弹层显示已配对设备（信号强度、上次同步时间）；开机在附近的可点「下载」，未开机的置灰。只有一台在线时可配置为自动直连（真正的一键）。
   - **增量同步**：连接后读取设备潜水清单（manifest），与本地 fingerprint 比对，只下载新增；完成后英雄区替换为最新一潜。
   - **双电脑去重**：每潜记录来源设备序列号；两台电脑（如 Perdix 3 + Peregrine 同时佩戴）记录的同一潜按开始时间邻近性自动识别，合并为一潜、保留双源数据可切换。
3. **日志本列表**：按时间倒序；每行 = 日期、潜点、最大深度、时长、迷你曲线缩略图。支持多选模式（批量标训练标签 / 批量关联潜点）。
4. **训练摘要卡**（列表顶部）：最近训练趋势迷你图，点击进入训练面板。

**潜水详情页**（列表点入，面向 GUE/技潜的精准数据）：分 section——

- **曲线**（可缩放）：深度 + 可切换的运行平均深度线（x̄，GUE 气体规划核心值）、水温、NDL；上升速率 >9 m/min 的段落直接在深度线上标红
- **概要**：最大/平均深度、时长、水温区间、最大上升速率、CNS 峰值
- **减压·气体**：减压模型与 GF 设置（如 GF 40/85，从日志头解析）、最低 NDL/最大 TTS、气体成分（O₂/He）、按最深点计算的气体密度 g/L（GUE 目标 ≤5.2）与 END、水型（淡/海水密度）与当日表面气压、采样间隔
- **训练评分**（若标记）、**潜点与笔记**（可编辑）、训练开关
- 未来：Shearwater 按键 Marker 事件（PNF `0x30` INFO_EVENT 记录）标注在曲线上——洞潜 jump/转向点回放用

以上字段全部来自 PNF 日志头/采样记录，偏移已对照 libdivecomputer 并用真实数据验证（GF 40/85、海水 1020、表面气压 1010–1015 mbar 等均正确解出）。

### Tab 2：地图

- 世界地图 + 潜点标记（pin 上显示该点潜数），支持横屏。
- **潜点录入**（已确认双路径）：
  - 潜点库 + 批量关联：地图长按或搜索地名建潜点 → 多选潜水批量关联
  - 手动逐潜标记：详情页里单独设置位置
- 数据现实：现有 47 潜均无 GPS（两台设备无 GNSS 芯片），全部依赖上述手动路径。
- 未来扩展位：潜点/潜水挂照片。

### 训练面板（从日志 Tab 进入，非独立 Tab）

只统计用户打了「训练」标签的潜水（已确认：训练潜与 fun dive 分开）。四个技能维度，顶部评分卡 + 各维度趋势详情：

1. **平稳度**：自动识别曲线平段（意图定深段），计算深度标准差；目标 ±0.5 m（GUE-F 标准）
2. **上升速率纪律**：逐段上升速率，>9 m/min 段标红，统计违规秒数
3. **停留质量**：识别 6m/3m 停（min deco 阶梯），统计实际停在目标 ±0.5 m 内的时间占比
4. **SAC 气耗**：无 AI 时手动填起始/结束压力 + 瓶规格，计算 L/min 趋势

附加：最近 N 次训练潜曲线半透明叠加对比。

## 数据流

```
Shearwater 设备 --BLE/GATT--> 下载模块 --原始PNF blob--> SwiftData
                                            |
                                       PNF 解析器 --> 采样序列 --> 图表/训练分析
```

- 下载使用 manifest + fingerprint：先取设备潜水清单，与本地比对，只下载新增。
- 原始 blob 永久保留；解析失败的潜水保留 blob 并标记，便于修复后重解析。
- 额外导入路径（次要）：从 Shearwater Cloud 桌面版数据库导入历史数据（一次性迁移工具，可后置）。

## 错误处理

- BLE 中断：分块下载带重试；失败保留已下载部分，下次续传。
- 解析异常：单潜解析失败不影响其余；blob 保留 + 标记待修。
- 空状态：无数据时英雄区显示引导（"连接你的潜水电脑"）。

## 测试

- PNF 解析器：以 47 潜真实数据为金标准（Python 解析结果作 fixture），Swift 解析输出必须逐字段一致。
- 训练指标算法：对选定潜水的人工核算值作单元测试。
- BLE 协议：真机联调（模拟器无 BLE）；协议层用录制的报文回放做单元测试。

## 里程碑

1. **M0 视觉原型**（网页，真实数据）：确认视觉方向 ← 当前

3. **M2**：地图 + 潜点库 + 训练面板
4. **M3**（可选）：Shearwater Cloud 导入、照片、App Store 上架
