# Aquaddict 🤿

A self-built iOS dive log for Shearwater dive computers — download dives over
Bluetooth, no Shearwater Cloud required, with GUE-oriented analytics that the
official apps don't have.

<p>
<b>潜水日志 iOS App</b> — 蓝牙直连 Shearwater 潜水电脑下载日志，深海暗色设计，
面向 GUE 技术潜水的数据分析。
</p>

## Features

- **BLE download** straight from the dive computer (Perdix 3 / Peregrine
  verified on real hardware; all Shearwater BLE models supported — one shared
  protocol). Incremental sync via manifest fingerprints.
- **Dive profile chart**: depth with water-column fill, running average depth
  (GUE gas planning), ascent-rate violations highlighted in red, water temp /
  instantaneous SAC / NDL / CCR ppO₂ overlays, touch scrubbing, fullscreen
  landscape view.
- **GUE training analytics**: buoyancy stability (flat-segment σ), ascent
  discipline (>9 m/min), stop quality, SAC/RMV trends across tagged dives.
- **Technical detail per dive**: GF settings, deco model, gas density (g/L),
  END, CNS, water type, surface pressure — parsed from the log's binary header.
- **Dive sites**: create by map long-press, auto-discover nearby named sites
  (Apple Maps + OpenStreetMap), batch-assign dives, GNSS pins from Perdix 3.
- **Buddies & photos** per dive (Contacts picker, camera / photo library).
- **Gas planner**: MOD, best mix, min He for END, gas density, min-deco
  ladder, GUE MinGas, rule of thirds, bottom gas.
- **Deco planner & tissue replay**: full ZHL-16C (16 compartments, N₂+He,
  gradient factors) — plan a dive with deco schedule, or replay tissue
  loading/GF99 over any logged dive.
- **Nitrox blender**: partial-pressure top-up math from current fill to
  target mix.
- **Weighting & trim**: transfer calculator (singles⇄doubles, fresh⇄salt,
  suit changes — calibrated against real measurements) and a landscape trim
  simulator (posture/gear effects on pitch).
- **Gear management**: US tank presets (HP/LP/AL), per-part drysuit service
  log, per-dive tank assignment for correct RMV.
- **More per-dive data**: species sightings, calorie estimate
  (ventilation-based, uses recorded water temp), fragment merging for
  training days chopped up by brief surfacings (reversible).
- **Year in Review**: swipeable story cards + shareable poster.
- **Destinations**: 40 world-class sites filterable by month / big animal,
  with season windows and a wishlist.
- **Records & badges**, bilingual zh/en (follows system), one-tap
  metric/imperial toggle.

Fresh installs show three sanitized sample dives (they disappear after your
first real download), so everything above is browsable without hardware.

## Building

```bash
# Core library tests (no Xcode project needed)
cd DiveKit && swift run divekit-tests

# The app
brew install xcodegen
cd DiveTraceApp
xcodegen generate
open DiveTrace.xcodeproj   # set your own team in Signing, then Run
```

Bluetooth requires a real device (no BLE in the simulator). Put the dive
computer in **Menu → Bluetooth**, then tap Download in the app.

## How the Shearwater protocol works

Serial-over-GATT: SLIP-framed packets over one vendor characteristic
(`FE25C237-…`, or `1AA44039-…` on Perdix 3). Application layer is
`FF 01`-headed request/response: RDBI identifiers (serial/firmware/model),
then an upload session (`0x35/0x36/0x37`) streaming the manifest and each
dive as 9-bit-RLE + XOR-compressed PNF blobs. PNF is a stream of 32-byte
records: opening/closing header blocks plus one record per sample.
Field offsets follow [libdivecomputer](https://github.com/libdivecomputer/libdivecomputer)
and are verified byte-for-byte against real dives in `DiveKit`'s test fixtures.
